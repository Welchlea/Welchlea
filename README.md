# Lea Welch

**Conversation designer. I design, test and measure how AI services talk to people.**

I design conversations for government digital services and regulated financial services. My focus now is evals: turning "what good looks like" into checks that run every time a prompt or a flow changes.

---

## What I am working on

### Testing AI replies
[convo-evals](https://github.com/Welchlea/convo-evals) checks chatbot replies for reading level, jargon, financial advice and a route to a person.

### Answers from approved content only
[grounded-answers](https://github.com/Welchlea/grounded-answers) is a help bot that says when it does not know and catches made-up facts.

### Flows that do not trap users
[flow-lint](https://github.com/Welchlea/flow-lint) finds dead ends, endless retries and missing handovers.

### Plain English at scale
[botcopy-lint](https://github.com/Welchlea/botcopy-lint) checks bot messages against a style guide.

### Learning from real conversations
[transcript-insights](https://github.com/Welchlea/transcript-insights) turns chat logs into a list of what to fix first.
